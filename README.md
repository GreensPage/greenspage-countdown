# Greenspage Countdown

**Launches deserve more than a date.**

Greenspage Countdown is a focused WordPress countdown block for launches, events, deadlines, and evergreen timers. It handles timezones and country-aware date formatting properly, gives you control over what happens at zero, and includes a one-click Launch Hero pattern for complete coming-soon sections.

## Features

- Fixed-date and evergreen countdown modes
- Country-aware date formatting
- Timezone handling
- Box and inline layouts
- Configurable units and labels
- Optional progress bar
- Four expiry behaviours: freeze at zero, hide, show a message, or redirect
- Launch Hero + Countdown block pattern
- Re-themeable launch pattern via CSS custom properties
- Accessible, labelled output with reduced-motion support

## Installation

1. Download `greenspage-countdown.zip` from the latest GitHub release.
2. In WordPress, go to **Plugins → Add New → Upload Plugin**.
3. Upload the zip and activate **Greenspage Countdown**.
4. Add the **Countdown** block, or insert **Patterns → Greenspage → Launch Hero + Countdown**.

## Requirements

- WordPress 6.3 or later
- PHP 7.4 or later
